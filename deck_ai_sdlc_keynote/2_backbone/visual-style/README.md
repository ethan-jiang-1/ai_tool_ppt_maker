# 视觉主干

**这里放什么:**
- `style-master-prompt.md` — 生成风格母版图的 prompt(源文件,别丢)
- `style_master.jpg` — 风格母版图投影(每页生图时的视觉锚,必须 .jpg；权威 selection 在 `_state/state.yaml`)
- `page-authority-visual-language.yaml` — 视觉语言注册表(recipes/compositions/motifs + provider clauses,管线读它)
- `visual-style.md` — 视觉风格说明(配色/字体/排版/素描模式)
- `style_master.image-task.json` — 风格母版图的 task trace(宪法要求后缀)

**你做什么:** 改配色/风格改这里。锁定后尽量别动——它是「全 deck 长一样」的根源。
