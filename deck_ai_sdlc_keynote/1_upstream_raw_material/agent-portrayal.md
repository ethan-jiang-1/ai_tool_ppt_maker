# Agent 形象规范（Agent Portrayal Spec）

> v1 在 25 页 slide 的 IMAGE PROMPT 中演化出了一套一致的 Agent 视觉词汇。本文件将其定义为 backbone 级规范，全版本共享。

## 通用 Agent 形象

在所有 slide 插画中，AI Agent 使用统一的视觉语言（"agent visual spec"）：

- **形态**：中性、无性别、琥珀色半透明玻璃/光体人形轮廓
- **内部**：可见拓扑网络结构（节点+连线），代表信息处理能力
- **左手**：持一本书（知识/规范的象征）
- **右手**：张开掌心朝上（协作/给予的象征）
- **姿态**：站姿或坐姿，自信但不具攻击性
- **表情**：无具体五官，通过姿态传达状态
- **与人的关系**：并肩而非对立——Agent 和人面向同一方向，而非面对面

## 具名 Agent 人格

v1 在具体 slide 中引入了具名 Agent 来体现"Agent 是 Partner 而非 interchangeable unit"的设计理念。每个具名 Agent 在上述通用形象基础上增加差异化：

### Yan（砚，Inkstone）
- **领域**：思考、写作、验证
- **视觉特征**：坐姿、执笔、面前整洁的输出（代码块、文档、测试用例）
- **笔触**：干净、稳定
- **首次出现**：s18_framed_autonomy
- **象征**：沉静、精确——"想清楚再写"

### Zhu（铸，Forge）
- **领域**：构建、连接、运行
- **视觉特征**：站姿、充满能量、操作设备/连接管道、周围是齿轮和仪器
- **笔触**：更粗、更有动感
- **首次出现**：s18_framed_autonomy
- **象征**：行动力、执行力——"把东西跑起来"

### Duo（舵，Rudder）
- **领域**：规划、编排、指挥
- **视觉特征**：居中、多条细线连接到其他 Agent
- **首次出现**：s20_allianz_nemo
- **象征**：协调——"一个 planner 指挥多个 specialist"

### He（核，Core Check）
- **领域**：核保检查
- **视觉特征**：手持放大镜/检查清单
- **首次出现**：s20_allianz_nemo
- **象征**：验证——"确认每一道关"

### Cha（察，Inspect）
- **领域**：欺诈筛查
- **视觉特征**：眼前有数据流/筛查界面
- **首次出现**：s20_allianz_nemo
- **象征**：警觉——"发现异常"

### Suan（算，Calculate）
- **领域**：理赔计算
- **视觉特征**：面前有算式/计算界面
- **首次出现**：s20_allianz_nemo
- **象征**：精确——"算清楚每一笔"

## 使用原则

1. **通用形象优先**：大部分 slide 使用通用 agent visual spec，只在需要区分多个 Agent 时引入具名人格
2. **具名 Agent 可复用**：同一 Agent 出现在不同 slide 时保持视觉特征一致
3. **不要每页都画新 Agent**：Agent 是 Partner，不是 interchangeable unit——画面中应体现"同一个伙伴出现在不同情境中"
4. **人不消失**：Agent 的旁边永远有人——委托、监督、验收的人

## 关于命名

具名 Agent 的中文名（砚/铸/舵/核/察/算）是 v1 的 convention。新 deck 可以沿用或自创命名体系，但需保持：
- 单字
- 描述能力而非身份
- 有可感知的人格特质
- 同一个 deck 内一致使用
