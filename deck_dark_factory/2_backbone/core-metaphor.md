# Core Metaphor

## 核心隐喻

```
"The Dark Factory" — a factory that keeps running when the humans leave the
floor. Not a better machine, not a smarter instruction sheet: a floor that has
been rebuilt so the work runs itself while people watch, audit, and decide.
```

## 为什么是这个隐喻？

它抓住的张力："It will not work here" —— 每次组织变革都被这句话挡住，2009 年的
continuous delivery 是，今天的 autonomous coding agents 也是。演讲者说：这句话真正
在说"我们还没准备好"，不是"技术做不到"。Dark Factory 给观众一个心智模型——把
"要不要上 AI 编码 agent"从工具选择问题，重新定义为"整个团队、平台、组织怎么围绕
自主 agent 重新搭建"的组织问题。

它可延展：整个 deck 每一页都在展开"工厂怎么重建"——团队动态（Block 2）、度量
（Block 3）、平台与组织（Block 4）、招聘与风险（Block 5）。演讲结尾甚至自己点破
"It's probably a dim factory"——按风险决定哪条产线全自动、哪条仍需人值守。这个隐喻
能撑起全部 13 页。

## 这个隐喻不是什么

不是"让 AI 完全取代人"的科幻图景。演讲明确说：不是所有 feature 都会变得自主，而是在
"微管理"到"自主审批"之间按风险选择档位。隐喻是组织重建，不是无人化。
