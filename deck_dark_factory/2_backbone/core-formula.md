# Core Formula

## 核心公式

```
Fewer Human Touches + One-to-Many Sharing = The Dark Factory
```

可证伪命题：只要 agent 的 harness、context、guidelines 足够好，组织里的自主工作就能
滚起来——人类干预逐步减少；而一次系统改进只要能被所有人复用，就会产生组织级乘数，
而不是单点 10x。

## 公式拆解

| 变量 | 定义 | 为什么必要 |
|------|------|-----------|
| Fewer Human Touches | 人类为了让 agent 做对事情而做的干预次数（prompt、修 output、补 spec） | 这是演讲唯一推荐的 productivity 指标之一——harness/context/guidelines 越好，这个数越低。它可度量，不靠感觉 |
| One-to-Many Sharing | 一次修复/优化被整个团队、平台、组织复用（solo → shared → multiplayer） | 演讲强调这不是"一个人变 10x"，而是"一处优化惠及所有人"。共享系统是把乘数放大的机制 |
| The Dark Factory | 自主 agent 在组织内可持续、规模化地运转 | 这才是真正的差异化。loops/harnesses 很快会商品化，组织结构才是不可复制的优势 |

## 怎么证伪这个公式

如果有人能证明：(a) 更强的 model 或更好的 prompt 本身就足以让组织获得 agentic
productivity，不需要重建团队/平台结构；或者 (b) 一次系统改进即使不共享也能产生组织级
收益——那么公式不成立，整个 deck 的论证就失败了。演讲反复用 2009 continuous delivery
来类比：当年以为"更快的手动部署"是关键，最后胜出的是重建了交付流程的组织。
