# Page Authority Working Papers

This directory makes the large parent roadmap reviewable. These are planning decisions and audit aids,
not runtime schemas or a substitute for future OpenSpec deltas.

| File | Purpose | Authority |
|---|---|---|
| `../unify-image2-page-authority.md` | Product decision, baseline, migration sequence, and program scope | Architecture summary |
| `active-protocol-contract.md` | Current protocol, source grammar, safe visual language, compositor, and readiness seam | Architecture decision |
| `visual-language-registry-contract.md` | Trusted visual-language registry grammar, compatibility, invalidation, and provider projection | Architecture decision |
| `legacy-compatibility-contract.md` | Read-only legacy observer and the sole adoption bridge | Architecture decision |
| `review-and-versioning-contract.md` | Raw/final review order and structural materialization transaction | Architecture decision |
| `agent-reference-contract.md` | Amber Agent doctrine, clean role derivatives, and provider-reference registry | Architecture decision |
| `main-spec-retirement.md` | Area-level main-spec cleanup inventory | Review aid |
| `main-spec-retirement-ledger.md` | Exact base Requirement disposition, target owner, and test obligation | Required pre-proposal evidence |
| `main-spec-retirement-audit.md` | Direct-vocabulary coverage audit that prevents missing affected Requirements | Required pre-proposal evidence |
| `contract-matrix.md` | Cross-contract closure checklist | Review aid |
| `review-log.md` | Finding disposition and re-review gate | Review aid |

Rules:

1. A working paper never creates a second runtime protocol or implementation requirement.
2. Every accepted finding must be reflected in the parent roadmap and a named working paper before a
   future change is proposed.
3. The exact ledger must match existing main-spec Requirement titles before proposal creation.
4. `Apply ready` requires strict validation and a clean review of future normative OpenSpec artifacts;
   it is not implied by a green status in this directory.
