# Main-Spec Retirement Inventory

## Decision

After the full program, `openspec/specs/` describes one current production family:

```text
page-authority-image2-v1
  -> pure-image2 | framed-image2 per slide
```

Historical `html-first-v1`, `whole-page-image2-v1`, `full-page`, `body+header-lock`, and visual-slot
facts remain readable only through `legacy-protocol-compatibility`. They must not survive as current
commands, modes, refresh routes, state paths, or equal product choices.

This inventory is target-state planning only. Current main specs remain truthful until the relevant
implementation lands. The exact companion checklist is
[main-spec-retirement-ledger.md](./main-spec-retirement-ledger.md), which has one row for every
affected current Requirement title.

## Dispositions

| Disposition | Meaning |
|---|---|
| Replace | Capability remains but its active requirement is rewritten for Page Authority. |
| Retire | Old active behavior and requirement disappear. |
| Collapse | Historical parsing/diagnostic facts move only to the legacy observer. |
| Keep | Protocol-neutral behavior stays, with a Page Authority regression test. |

## Area Inventory

| Area | End state |
|---|---|
| Source, mode, state, and CLI | One Page Authority resolver; exact legacy adoption or repair diagnostics. |
| Image generation and review | Receipt-bound raw evidence, accepted raw coverage, unified final manifest, final visual projection, and delivery decision. |
| Framed output | Typed compositor over full-canvas text-free underlay; no header-lock or HTML-first output route. |
| Agent identity | Backbone model sheet as doctrine; clean role derivatives through a separate Image2 registry. |
| Structural/adoption versioning | Hash-bound provider-free preview/apply; target-owned unreviewed materialization only inside apply. |
| HTML/visual-slot legacy | No current output path; browser/font primitives survive only behind the Framed compositor. |
| Run bundle, workflow, docs, and tests | Page Authority is the sole current vocabulary; legacy is bounded and observable. |

## Cleanup Proof

Future implementation cannot claim completion until exact ledger rows prove that legacy terms occur only
in the compatibility reader, migration/removal scenarios, and historical fixtures; no active adapter,
CLI help, Controller node, state completion rule, or normal refresh path offers a retired route.
