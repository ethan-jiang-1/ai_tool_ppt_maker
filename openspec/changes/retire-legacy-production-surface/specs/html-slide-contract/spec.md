## REMOVED Requirements

### Requirement: HTML-first source produces one validated structured slide plan
**Reason**: HTML-first is no longer a current source protocol.
**Migration**: Use Page Authority source or bounded legacy adoption.

### Requirement: Structured YAML is a closed JSON-like value tree
**Reason**: The HTML-owned structured source grammar is retired.
**Migration**: Use Page Authority source grammar.

### Requirement: Structured plan envelope is explicit and self-identifying
**Reason**: HTML slide-plan publication is retired.
**Migration**: Use Page Authority source receipts.

### Requirement: V1 typed blocks have fixed shapes and capacities
**Reason**: HTML family block semantics are retired.
**Migration**: Use Page Authority Visual Brief and Text Frame contracts.

### Requirement: Markdown-owned visible headers have v1 source capacities
**Reason**: HTML header capacity rules are retired.
**Migration**: Use Page Authority Text Frame preflight.

### Requirement: V1 layout family registry is a closed discriminated union
**Reason**: HTML layout family selection is retired.
**Migration**: Use current Page Authority visual-language/frame registries.

### Requirement: Primary visual and fallback contracts are closed and locally complete
**Reason**: The HTML primary-visual contract is retired as a production source authority.
**Migration**: Use the Page Authority visual/reference registry.

### Requirement: Slot geometry is canonical and source contains no pixels
**Reason**: HTML visual-slot geometry is retired.
**Migration**: Use Page Authority authority/frame evidence.

### Requirement: Source preflight validates capacity and actual font coverage
**Reason**: HTML source preflight is retired; retained font runtime is separately owned.
**Migration**: Use Page Authority source and Framed runtime preflight.

### Requirement: Selection resolution separates fallback validity, asset integrity, and applicability
**Reason**: HTML catalog selection is not a current production authority.
**Migration**: Use the Page Authority reference registry.

### Requirement: Fingerprint projections have separate stable purposes
**Reason**: HTML fingerprint projections are retired.
**Migration**: Use Page Authority receipt/raw/final evidence digests.

### Requirement: Source and config fields have one explicit invalidation classification
**Reason**: HTML source invalidation is retired.
**Migration**: Use Page Authority invalidation ownership.

### Requirement: Structured source round-trip preserves non-owned Markdown
**Reason**: The HTML structured round-trip is retired.
**Migration**: Use the Page Authority source editor contract.

### Requirement: HTML and whole-page source contracts are disjoint
**Reason**: Neither historical source contract is current production.
**Migration**: Use the single Page Authority source protocol.
