## REMOVED Requirements

### Requirement: Stage 3 overlays header text on images
**Reason**: Canvas Header-Lock is a retired production authority; Framed finalization owns current deterministic text composition.
**Migration**: Use Page Authority Framed composition or adopt a historical run before new production work.

### Requirement: Stage 3 is a standalone ESM script
**Reason**: The standalone Header-Lock executable is retired.
**Migration**: Use the Page Authority CLI and finalizer.

### Requirement: Stage 3 follows resolved render mode regardless of its source
**Reason**: Retired render modes no longer resolve in current production.
**Migration**: Resolve Pure or Framed authority through Page Authority source receipts.

### Requirement: Hard overlay and full-page soft contract share real visual config geometry
**Reason**: The historical header contract is not a current visual authority.
**Migration**: Use the Page Authority Text Frame and Framed compositor contract.

### Requirement: Stage 3 publishes an ID-addressed final-image manifest
**Reason**: The current final manifest is owned by Page Authority, not Header-Lock.
**Migration**: Consume the Page Authority final manifest.

### Requirement: Target versions rebuild Stage 3 locally from verified raw inputs
**Reason**: Target-local finalization is now Page Authority Framed composition.
**Migration**: Use Page Authority raw materialization and finalization.
