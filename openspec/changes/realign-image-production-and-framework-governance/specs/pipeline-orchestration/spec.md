## ADDED Requirements

### Requirement: Orchestration preserves mode-owned Image Production behavior
Orchestration SHALL select whole-page or visual-slot adapters from canonical mode and current direct evidence while preserving existing public CLI arguments, envelopes, provider-load isolation, artifacts, provenance, and recovery behavior.

#### Scenario: Adapter relocation is behavior-preserving
- **WHEN** an existing public production command runs after relocation
- **THEN** its selected adapter preserves its prior observable contract
