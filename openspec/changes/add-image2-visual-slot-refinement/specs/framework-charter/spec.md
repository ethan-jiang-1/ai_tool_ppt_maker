## ADDED Requirements

### Requirement: Human controls modern Image2 cost and adoption

Charter guidance SHALL assign Agent recommendation to MD, exact cost/visual authorization and per-page adoption to the human, and provider submission/provenance enforcement to Phase 4. It SHALL distinguish modern visual-slot refinement from Phase-5 legacy whole-page maintenance.

#### Scenario: Agent recommends pages
- **WHEN** the Agent identifies high-value visual slots
- **THEN** it requests human authorization rather than treating recommendation as permission
