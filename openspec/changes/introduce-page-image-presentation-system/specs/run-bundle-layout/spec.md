## REMOVED Requirements

### Requirement: Run-Bundle Layout owns the Pure visual-system source location

**Reason**: A Pure-only source cannot own the shared V2 Page Class catalog or
the selected Framed projection.

**Migration**: V2 source uses the fixed Page Image Presentation System package.
Non-V2 input remains byte-preserved and is never silently converted.

## ADDED Requirements

### Requirement: Layout owns V2 presentation source and Data View paths

Run-Bundle Layout SHALL reserve the Page Image Presentation System package at
`2_backbone/visual-style/page-image-presentation/`, with normal same-name
`overrides/visual-style/page-image-presentation/` precedence for a version.
The package SHALL contain only `page-classes.yaml`, `deck-baseline.yaml`,
`pure-profiles.yaml`, and `framed-header-profiles.yaml`; a newly initialized V2
Run Bundle SHALL receive valid seed records at backbone.

Layout SHALL also reserve rebuildable non-authoritative
`_generated/page_image_workflow/pre-production-data/`, its
`presentation-control-map.json`, and per-slide leaf names. Package files are
canonical inputs; the derived root is never source, lifecycle owner, or Human
Navigation replacement.

#### Scenario: A new V2 bundle receives the fixed package

- **WHEN** a new Run Bundle is initialized
- **THEN** backbone contains exactly the four valid presentation source files
- **AND** none is seeded in `_generated/` or lifecycle storage

#### Scenario: A version overrides one presentation input

- **WHEN** a V2 version supplies one valid same-name source override
- **THEN** V2 planning resolves that file while siblings retain backbone
  selection
- **AND** no generated artifact, receipt, grant, or review record is mutated by
  the source edit alone

#### Scenario: Non-V2 inspection remains observational

- **WHEN** layout inspection encounters a non-V2 source/state pair lacking the
  package
- **THEN** it preserves source, State, and generated bytes without seeding,
  copying, or inferring package content
- **AND** the protocol evaluator supplies the generic hard-stop before planning
