## MODIFIED Requirements

### Requirement: Commands describe refinement as optional visual-slot work

`COMMANDS.md` SHALL route an explicit post-delivery professional visual upgrade to the Phase-4
controller, disclose that it is optional and cost-authorized, and preserve the immediate HTML-complete
exit. It SHALL not present Image2 as a renderer selection or whole-page replacement. When current HTML
delivery evidence is incomplete but target-version final-slide/slot inputs are identifiable, guidance
MAY recommend the offline `image2 plan --force --reason` continuation as an explicit user choice; it
SHALL explain that the prerequisite waiver does not authorize provider work, candidate promotion, or
completion without a new final review.

#### Scenario: User asks for a professional upgrade

- **WHEN** a completed HTML deck has candidate visual value
- **THEN** guidance offers recommendation and exact authorization rather than starting provider work

#### Scenario: User explicitly continues despite delivery evidence risk

- **WHEN** the user accepts a bounded prerequisite risk with a reason and current final-slide/slot identity is valid
- **THEN** guidance offers the offline planning command
- **AND** it keeps authorization, generation, promotion, and final review as separate explicit steps
