# Design Constraints

## Audience

企业管理层 / 决策者（战略 keynote）。有商业与管理常识，但多数非技术背景；他们要判断"AI 会如何重构自己的组织与行业"，需要可信的先行样本与可迁移的框架，而不是技术实现细节。

## Language and Tone

slides 中文为主（英文仅专有名词 SDLC / BPM / Fable 5 / TDD 与英文讲者的直接引语）；演讲中文，可切换英文。语气温暖、智识、有人味，自信但好奇。证据标准：每个案例必须标注已知局限——数据范围、因果关系、失败教训；诚实不是削弱说服力，而是建立可信度。

## Forbidden Claims

- 不宣称 AI 会取代一切白领工作，不给必然的岗位消失时间表。
- 不把 Allianz -80% 当作全品类效果——它只适用 narrow 类别（食物腐败 <AUD$500）。
- 不把 Block 40% 裁员归因为纯 AI——主因是成本削减（超招、股价、CFPB 罚），AI 真实但次要。
- 不把相关性直接断言为因果，除非有独立分析师判定（如 Cloudflare 结构性重组）。
- 不把 Maersk TradeLens 当作成功案例——它已 $100M+ 关停，须如实呈现。

## Required Terminology

- Information Chain（信息加工链）：Input → Transformation → Output。
- Trust Gap（信任鸿沟）：瓶颈第一次从机器变成人。
- Framed Autonomy（有框自主）= AI Sandwich（SDLC 侧）：人定边界 + Agent 在框内执行。
- SDLC（软件开发生命周期）、BPM（业务流程管理）、Agentic BPM。
- Fable 5、TDD、Dunbar 数（7-15）、Builder / Seller / Measurer（Drucker 1954）。
- 具名 Agent 人格：Yan（砚）、Zhu（铸）、Duo（舵）、He（核）、Cha（察）、Suan（算）。
