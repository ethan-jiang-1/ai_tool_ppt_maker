# CURRENT v1 compatibility: Page Authority Image Production

This legacy method-module description applies only to an existing exact
`page-authority-image2-v1` / `image2-page-authority` mixed run. It is not a
new-authoring route and does not own target Framed, Pure, delivery, or iteration
behavior. New v2 work follows `03-framed-image XOR 04-pure-image ->
05-delivery -> 06-iteration`.

Classify requested changes by final-pixel owner and invalidated evidence:

| Change | Compatibility path |
| --- | --- |
| Framed Text Frame-only | Header Text & Style Refresh |
| Pure display text, visual brief, reference, or underlay | Generated Image Rebuild |
| Speaker notes only | Notes-Only Refresh |
| Add, remove, move, reorder, or authority change | Structural Versioning Path |

Never edit `_generated/`, inherit approval or delivery evidence into a target
version, or call a provider from a local Framed refresh. Structural work previews
the exact stable-ID impact and applies only a confirmed plan hash.
