# Deck System Contract — Clean Clinical
# Renderer-neutral natural-language constraints. Structured values live in color_palette.json.

LANGUAGE: English by default; Hans is allowed only when the deck language requires it and bundled coverage verifies.
DECK TYPE: Data-driven report, clinical keynote, or training deck. One clear finding per slide.
BACKGROUND: White #ffffff. Panels #f1f5f9. No dark or gradient background.
COLOR: #1e293b text, #0d9488 positive, #0284c7 emphasis, #d97706 only for genuine warning.
TEXT: Accurate text comes from structured source and the HTML compositor. Keep under 40 words, max 5 body zones, readable labels, max 3 KPIs.
COMPONENTS: Clean cards, tables, bar/line charts, restrained line icons, one-sentence callout. No 3D, stock art, fake UI, microtext, logos, watermark, or page number.
TONE: Rational, evidence-based, precise, clinical without feeling cold.
