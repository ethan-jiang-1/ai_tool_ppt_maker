深紫背景、cyan KPI、magenta emphasis。大胆但仍服从可读性、fixed geometry 与有限组件数量，不能退化为霓虹装饰墙。

| Role | Value |
|---|---|
| background | `#1a0a2e` |
| panel | `#2d1b4e` |
| primary text | `#e0e0e0` |
| secondary text | `#a0a0b8` |
| accent | `#00f5d4` |
| emphasis | `#f72585` |
| data | `#7209b7` |
