# Validate The HTML System

Run local preview to render production-equivalent representative pages. Review actual typography, spacing, chart treatment, fallback visuals, component recipes, overflow, and contact sheet, then approve the exact current visual review plan.

Global token/renderer/geometry changes require representative coverage. Ordinary copy does not invalidate the whole visual system; page-local asset, chart-shape, family, or fallback changes refresh affected page evidence. A selected asset must also show forced-fallback review evidence.

Metadata mirrors are status only. Authoritative approval is version- and reset-bound state evidence.
