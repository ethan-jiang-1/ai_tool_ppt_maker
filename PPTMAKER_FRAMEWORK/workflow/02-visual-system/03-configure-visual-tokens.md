# Configure Page Authority Visual Inputs

Maintain the Page Authority visual-language registry and reference profiles as
the current visual inputs. Each source `VISUAL BRIEF` selects registered values;
each reference role is confined, fingerprinted, and validated before raw work.

The Framed compositor consumes only its fixed Text Frame contract and current
visual inputs. It is a local finalization seam, not a general page renderer.
