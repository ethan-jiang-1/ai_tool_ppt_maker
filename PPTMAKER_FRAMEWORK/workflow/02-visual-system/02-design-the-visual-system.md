# Design The Visual System

Translate audience, subject, and medium into a restrained palette, hierarchy, density, component language, chart treatment, fallback image language, and asset policy. Choose one checked-in preset as a schema-valid base, then edit the human-owned token source.

Design for the ten closed families and their real content relationships. Do not create a second theme file or encode page coordinates in slide source. Typography uses bundled Source Sans 3 and Noto Sans SC roles; geometry remains registry-owned.
