# Content And Layout Iteration

Edit the canonical structured source. Ordinary header/body copy changes rebuild affected local pages and stale content review when semantics change; they do not reapprove the whole visual system. Family, typed-block, chart-shape, fallback, or selected-asset changes refresh the affected visual evidence.

Run validate, scoped HTML Stage 2/3 review, then continue Stage 4/5 only after current reviews. Never translate the edit into an Image2 page prompt.
