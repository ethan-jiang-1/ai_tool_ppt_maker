# Content And Layout Iteration

Edit the canonical Page Authority source. A Framed Text Frame-only change uses Header
Text & Style Refresh; a Pure display-text, Visual Brief, reference, or underlay
change uses Generated Image Rebuild. Notes-only changes use Notes-Only Refresh, and
structural edits use Structural Versioning Path.

Run validate, create or refresh only the affected receipt-bound raw plan, accept the
current raw review, then finalize, assemble, and inject notes. Never hand-edit
generated artifacts or introduce a second production route.
