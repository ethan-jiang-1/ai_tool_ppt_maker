# End-To-End HTML-First Walkthrough

1. Run base doctor and initialize a mnemonic HTML-first deck.
2. Author structured slides and renderer-neutral visual tokens/assets.
3. Validate and run local preview to publish content/visual review plans and real contact-sheet evidence.
4. Record current content and visual decisions.
5. Build local Stage 1-5, inspect delivery contact sheet/PPTX/notes, and record final delivery review.
6. Iterate through Local Slide Rebuild, Local Deck Rebuild, Notes-Only Refresh, or Structural Versioning Path.

No step needs a style master, Image2 environment, provider call, or Phase 4 node. A current accepted deck is complete after Phase 3 delivery review.
