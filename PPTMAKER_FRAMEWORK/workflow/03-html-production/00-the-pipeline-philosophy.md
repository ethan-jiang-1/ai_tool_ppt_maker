# HTML Complete First

The default product line is structured source -> self-contained HTML -> measured final-slide PNG -> provider-neutral PPTX -> notes. Every stage is local, receipt-bound, and selected by the canonical production marker before readiness or writes.

Preview is cheap and may run before approval. Delivery waits for current content and visual evidence. Immutable objects preserve reader safety; current manifests are the authority. Reset is a state-first whole-owner transaction, never manual generated-file surgery.

First-class whole-page Image2 work is owned by the Phase-4 `create-deck` adapter. Modern Image2 refinement is not part of this phase; it is an optional separately authorized Phase-4 workflow after current delivery.
