# 05 - 导入已有 deck

外部素材先进入新的 canonical run bundle，由 Agent 重写当前 source/control；不把旧 run、generated bytes、gate、receipt 或 provider authorization 迁入当前框架。

跨 pipeline 不是导入兼容路径。它只使用现有的 state-owned production-mode transition：准备目标 mode、预览显式 target source/control、确认 exact plan hash、发布 target，再按 receipt-bound handoff 继续。所有操作通过 `ppt_flow state <run-dir> --*-production-mode-transition` 执行。

不要通过补写 source marker、复制 `_generated/`、手改 state/journal，或从旧 prompt 推断结构化内容来恢复旧 run。没有可用当前 marker/state 的旧 run 必须重建。
