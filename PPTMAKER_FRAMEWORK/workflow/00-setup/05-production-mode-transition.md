# 05 - 跨 pipeline 页面权限切换

跨 pipeline 变化保留 source version，同时由 Agent 显式编写目标 source、control 和 intake；不把 source prompt、pixels、generated bytes、gate、receipt 或 provider authorization 带入目标。

所有操作通过 state-owned `production-mode-transition` 执行：准备目标 mode、预览显式 target source/control、确认 exact plan hash、发布 target，再按 receipt-bound handoff 继续。`--confirm-production-mode-transition` 记录目标 intake 的用户 `proceed` 决定，是 exact transaction commit，不是 Gate Policy 的风险 `confirm`，不接受 `--reason` 或 `--force`。CLI 只使用 `ppt_flow state <run-dir> --*-production-mode-transition` 的封闭操作。

不要通过补写 source marker、复制 `_generated/`、手改 state/journal，或从旧 prompt 推断结构化内容来恢复不受支持的 run。没有可用当前 marker/state 的旧 run 必须创建新的 current run。
