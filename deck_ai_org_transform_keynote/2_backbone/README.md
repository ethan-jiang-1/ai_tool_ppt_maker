# 中游:主干(backbone)

**这里放什么:** 整个 deck 的骨架,全版本共享的「默认事实源」:
- `core-metaphor.md` — 核心隐喻
- `core-formula.md` — 核心公式
- `design-constraints.md` — 内容约束(受众/语言与语气/禁忌主张/必要术语)
- `story-outline.md` — Block-first 叙事主干
- `manuscript/` — 讲稿主干
- `visual-style/` — 视觉主干(见里面的 README)

**你做什么:** 改这里 = 影响所有版本。想只改某一版,去那一版的 `overrides/`。
