# 上游：原始素材

这里存放喂养 deck 的调研、参考资料、事实来源和研究摘要。外部 `dpt_*` 目录是原始材料的 source of record；本目录只保存来源索引、消化后的摘要和可复用摘录。

本目录按“材料来源”组织，不按页面、章节或 Block 组织。下游如何组合这些材料，由 `2_backbone/` 和具体版本 source 决定。

每份外部材料都保留一个 `source-*` symlink，摘要与原文可以互相回溯；symlink 不复制或修改外部原始文件。讲者本人材料放在本地目录 `source-speaker-bio/`，不是外部 `dpt_*` 链接。
