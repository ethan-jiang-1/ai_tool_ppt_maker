# 06-iteration

This target method module reads the bound version workflow and direct artifact
freshness to choose one legal refresh route. It does not recreate Framed, Pure,
or Delivery implementation.

Framed work composes locally only with exact compiled provider input, protected
geometry, raw contract, and local header profile; all other pixel-relevant
changes rebuild raw; notes-only work goes to Delivery. Insert, delete, reorder,
and Framed/Pure switches use previewed
exact-hash Structural Versioning Path.

Changing a page's selected `PAGE CLASS`, deck default, or selected presentation
profile requires Generated Image Rebuild and a new Complete Page Review. A valid
edit to an unselected sibling profile leaves that page's current binding alone,
but every package document must still validate. Repair a malformed package at
its named source and rerun the same planning checkpoint; do not create a
separate refresh path or gate.
