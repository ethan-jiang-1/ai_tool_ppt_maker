# Validate The Page Image Visual System

Validate the Page Image visual-language registry, reference eligibility, and
Framed Header Rendering Policy inputs before raw work. Review the current complete
page projection and its coverage, then record the explicit Complete Page Review before
finalization.

Registry, reference, or header-profile changes invalidate the affected raw or
Framed evidence according to the selected version workflow. Header literals,
Provider Content Schema, visual, or geometry changes rebuild raw. A
selected reference must remain registered, fingerprinted, and role-eligible for
the current raw profile.

Metadata mirrors are status only. Authoritative approval is current raw-review and
delivery evidence bound to the Page Image source epoch.
