# Why Page Authority Is Explicit

Every version needs a clear final-pixel workflow. Target Page Authority records
it once in source: `pure` assigns every final pixel to Image2, while `framed`
keeps the visual underlay in Image2 and assigns final text pixels to the fixed
local Text Frame. Every target slide inherits that choice.

The visual-language registry keeps recipes, compositions, motifs, identities, and
negative constraints reviewable. This makes invalidation explicit: a Text Frame
change can remain local, while a visual brief or reference change renews raw
evidence.
