# 03-framed-image

This target method module owns the `framed` workflow: `standard-v1` Text Frame
fit/preflight, reserved text-free underlay rectangles, typed raw contribution,
and local final composition from accepted raw evidence. It publishes the common
v2 final-slide manifest and never assembles PPTX, injects notes, or calls Pure.

An exact-evidence Text Frame-only change may compose locally. A preset,
underlay, or visual-contract change invalidates raw work and returns to shared
authorization/review.
